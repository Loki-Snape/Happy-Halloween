# Happy Halloween — Web Showcase

A compact, polished web showcase with a Halloween theme — spooky, modern, and professional.

## Overview

This small project contains a set of themed HTML pages, styles, and a lightweight script to create an interactive Halloween experience suitable for demos, portfolios, or seasonal microsites.

## Features

- Clean, responsive layouts
- Themed pages: main landing, mummy, vampire, and a resume page
- Small, focused JavaScript for interactivity

## Preview (Quick)

Open `index.html` in your browser, or serve the folder locally for full asset behavior.

Recommended (from project root):

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

Or, if you prefer Node-based servers:

```bash
npx http-server -p 8000
```

## Project Structure

- [index.html](index.html) — Landing page
- [mummy.html](mummy.html) — Mummy-themed page
- [Vampire.html](Vampire.html) — Vampire-themed page
- [Resume.html](Resume.html) — Resume / info page
- [script.js](script.js) — Small interactive behaviors
- [style.css](style.css) — Global styles and theme

## Usage

- Edit the HTML files to change content and images.
- Tweak `style.css` for visual adjustments and theming.
- `script.js` contains simple hooks for animations and interactions.
