# Happy Halloween

A spooky, polished Halloween-themed portfolio and resume experience built with HTML, CSS, JavaScript, and Three.js. The project blends a dark atmospheric style with a professional presentation, so it feels festive without losing clarity.

## Overview

This site includes multiple themed pages and an interactive resume presentation designed to make a strong first impression. It is meant to be lightweight, visually engaging, and easy to explore.It is themed around halloween and contains mummy, vampire and zombies.

## Features

- Halloween-inspired visual styling
- Interactive 3D resume experience
- Separate themed pages for different characters and sections
- Responsive layout and modern front-end structure

## Project Structure

- `index.html` - main landing page
- `mummy.html` - mummy-themed page
- `Vampire.html` - vampire-themed interactive resume page
- `Resume.html` - resume page
- `style.css` - shared styling
- `script.js` - shared behavior and interactions

## Run Locally

Open `index.html` in your browser, or serve the folder with any simple local server for the best experience.

## Notes

This project is intentionally simple, but the overall tone stays professional: dark visuals, clear structure, and just enough Halloween personality to stand out.
